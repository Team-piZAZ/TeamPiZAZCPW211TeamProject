# TeamPiZAZCPW211TeamProject
This project is a collaboration between Anthony Brunner, Zac Kimball, and Zane Marcoe. We are 
working together to create a comprehensive software solution for our team project. Our goal for this
project is to create a user-friendly WindowsForm application that will list 10 popular Anime's over
the years. The application will allow users to view information about each anime, including its title, 
genre, release date, and a brief description.

## Getting Started
- Clone or Download repository
- Download .NET 10 SDK
- Recommended Visual Studio 2026
- Open in VS 2026 and hit run

## Technologies/Frameworks Used
- Entity Framework Core
- MSSQL

## Possible Upcoming Features
- Letting users add their own anime to the list
- Favoriting or saving anime to a personal list
- Adding a search feature to find specific anime
- Adding a rating system for users to rate anime
